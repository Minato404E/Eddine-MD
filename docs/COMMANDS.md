# Commands

All bot responses are in English. Prefix defaults to `.` and can be changed per account.

## General

- `.menu`
- `.help`
- `.info`
- `.ping`
- `.alive`
- `.owner`
- `.jid`

## Account

- `.public`
- `.self`
- `.setname <name>`
- `.setprefix .`
- `.setimage <command> (reply to image)`
- `.youtube on|off`
- `.autoreply on|off`
- `.sudo add|del <phone> | sudo list`
- `.pair (private; your own account)`
- `.unpair confirm`
- `.settings`
