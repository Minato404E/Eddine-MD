# Third-party assets

- Anime clips: individual origin URLs and anime attribution in `reactions/credits.json` (Nekos.best responses). No claim of ownership over source anime artwork.
- Emoji Kitchen: Google artwork downloaded on request from gstatic; bundled combination index derived from https://github.com/xsalazar/emoji-kitchen-backend (metadata.json). No paid API. Unsupported pairs return a clear error.
- DejaVu Sans: bundled font and license in `fonts/`.
- Tesseract fast trained data: English, French, Arabic from https://github.com/tesseract-ocr/tessdata_fast ; Apache 2.0 license in `ocr/LICENSE.txt`.

All external assets keep their respective ownership. The project license should be chosen by the repository owner before publication; no license for third-party artwork is implied.
